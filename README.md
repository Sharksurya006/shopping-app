# NAYARA frontend
```
cd frontend && npm install && npm run dev
```
React + Tailwind + Zustand monolith (customer site + `/admin`). All data/services are mocked in `src/data` and `src/services`. Theme tokens live in `src/index.css`; toggle persists in localStorage. Product images are placeholders from picsum.photos — replace in `src/data/products.js`.
